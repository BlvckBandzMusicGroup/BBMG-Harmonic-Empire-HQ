# Security Policy

## Public Safety Rule

Do not commit secrets, API keys, access tokens, private keys, `.env` files, student personal data, or internal business credentials.

## If A Secret Is Accidentally Committed

1. Revoke the exposed secret immediately.
2. Rotate the credential.
3. Remove it from the repository history if needed.
4. Document the incident internally.

## Contact

For security concerns, contact BBMG through the official support channel.
