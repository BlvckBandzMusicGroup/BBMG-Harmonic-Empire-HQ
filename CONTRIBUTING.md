# Contributing

This repository is maintained by Blvck Bandz Music Group.

## Contribution Rules

- Keep public-facing materials professional.
- Do not add secrets or private internal documents.
- Use clear commit messages.
- Keep brand spelling consistent: Blvck Bandz.
- Place documentation inside `/docs` when possible.

## Commit Style

Use simple commit messages:

- `docs: add repository map`
- `brand: update public system notes`
- `site: update landing page copy`
- `ops: add launch checklist`
